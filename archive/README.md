# Retired prototypes

`tree-intro/` preserves the previous homepage, corner-tree renderer and dissolve transition from the design exploration. The active homepage uses `assets/tree/` instead. Nothing in this folder is loaded by the active site, served by the local preview, or included by the branch-root GitHub Pages build.

The old motion tests can still be run explicitly with `node --test archive/tree-intro/motion.test.mjs`. These files are historical references, not a second supported implementation.
