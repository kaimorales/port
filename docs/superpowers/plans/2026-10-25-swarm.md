# Visible swarm and editable circuit implementation plan

User approved the swarm and reshaping design. Keep this local, on the existing feature branch.

Goal: show every actual candidate attempt in a coherent round, let visitors reshape the circuit while preserving learned weights.
Architecture: the worker evaluates all 16 candidate networks and returns their complete traces plus incumbent and winner. The UI animates that immutable round before committing its result and requesting another. An edit session pauses and discards any uncommitted round, deforms the track, and initializes a new worker using the last committed weights.
Tech: vanilla JS modules, Canvas 2D, existing worker and fixed simulation.

- [x] Core and tests: return 16 traces, incumbent and winner index; add validated local deformation without mutating inputs; test incumbent selection and weight reuse.
- [x] Visible round: animate all 16 challengers and incumbent, draw only elapsed trails, stop crashed cars, show failure markers and completion counts. Pause freezes playback; speed changes playback only. Reveal selected driver at round end. Never swap traces midlap.
