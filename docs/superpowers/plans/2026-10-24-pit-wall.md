# Pit wall Implementation Plan

**Goal:** Add a playable race-strategy experiment behind one quiet homepage link.
**Architecture:** Standalone static page. A pure model module simulates 24 laps and searches all 368 one-stop strategies. A separate browser module owns controls, playback and the post-race strategy map.
**Tech stack:** Native HTML, CSS, SVG, ES modules, Node built-in tests. No dependencies or external services.

## Approved direction and visual contract
User authorized building the proposed race-strategy experiment and showing a finished preview. Preserve homepage painting, typography and layout. New page uses white #ffffff, ink #30332f, green #386450 for the player, orange #b16d44 for the solver, blue #688da7 for rain, light surface #f4f6f4. Georgia titles/observations, Arial labels/data. Signature: two cars on a hand-drawn fictional circuit, followed by an explorable strategy landscape. Full game under pit-wall.html; homepage adds only a pit wall link.

## Limits
This deliberately simplified, deterministic race assumes perfect forecast knowledge. Optimal means optimal among the supported one-stop strategies, not real-world F1. No real racing data, accounts, audio, telemetry, libraries or network requests. Remains local until publication is requested.
