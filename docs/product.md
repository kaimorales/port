# Product

## Register

brand

## Users

People exploring Kai Morales's work, collaborators, and potential employers. They should get a clear sense of the person quickly and choose what to explore.

## Product Purpose

A quiet personal portfolio with separate project and experience pages, a playable driving experiment, and a conversational guide to public information about Kai, with a separate API backend.

## Brand Personality

Quiet, curious, handmade. An old academic's personal HTML site with careful modern typography and interaction. Existing references are the user's pastoral painting and a detailed green ASCII tree inspired by asciiFlowers.

## Anti-references

Generic portfolio cards, dashboard panels, floating chatbot bubbles, unskippable loading screens, tree particles drifting over text, a tiny corner tree, fake terminal styling, filesystem slashes, and large amounts of simultaneous content.

## Design Principles

1. Preserve direct navigation and let visitors choose their depth.
2. Use the detailed tree only at startup, where its characters assemble into the actual page.
3. Use the user's real public work as content. Identify AI answers, admit missing facts, and never substitute sample replies for an unavailable backend.
4. Keep the original painting, white background, serif type, and social icons.
5. Prototype visually before adding an API or publishing.

## Accessibility & Inclusion

Native links and forms, keyboard interaction, visible focus, readable contrast, reduced-motion support, and a motion pause control. Responsive down to narrow mobile screens.
