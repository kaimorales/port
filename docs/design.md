# Portfolio design

## Scene

A visitor opens a personal page in an ordinary browser, pauses at a pastoral painting, and browses or asks a question in a calm, unhurried setting.

## Theme and palette

White background is an explicit user preference. Existing charcoal #30332f, body #4d524b, muted #687064, and blue links #375b8a. Rich green belongs to the ASCII tree. The painting supplies the remaining colors. Restrained color strategy.

## Typography

Retain deliberately chosen Georgia for the identity, prose, and controls. Arial for short utility notes; Courier New only for the actual ASCII artwork. No new external fonts.

## Layout

The homepage uses the painting as a generous, lower-cropped masthead, a compact identity block and navigation, then an understated question field. The tree appears only during startup. Inline answers draw on the user-authored Markdown profile. Small screens stack gracefully. No modal, floating tree, boxed cards, or chat bubbles.

## Motion

Approved startup direction: a detailed tree grows on white, then its characters move into destinations sampled from the actual painting, typography, links, and chat field. The assembled ASCII page resolves into usable DOM. No permanent tree, floating particles over live text, or dissolving-tree transition. The intro plays on each homepage load or refresh, without session-memory gating or a replay control. Reduced motion skips it, as do old section hashes that redirect to standalone pages. Skipping, resizing, or hiding the tab releases the page immediately.
