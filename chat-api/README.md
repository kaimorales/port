# Portfolio chat API

Zero-dependency Node 24 API. The static portfolio sends `{question, history}` to `/api/chat`; replies are `{answer}` or `{error:{code,message}}`. The server always calls OpenAI `gpt-6-luna` with reasoning effort `none` and at most 80 completion tokens. The prompt asks for one short paragraph under 40 words, usually one or two sentences. The API also collapses model whitespace so replies display as one paragraph. Browser input cannot choose a model or supply provider credentials. Question limit: 600 characters. History: up to six user/assistant entries, 2,000 characters each and 8,000 combined. JSON body: 16 KiB. Answers are limited to 4,000 characters. Requests must have an exact allowed Origin and JSON Content-Type. No transcript logging or storage is implemented.

For local preview, run `npm run dev` from the repository root and open `http://127.0.0.1:8765/`. Set `OPENAI_API_KEY=...` in `chat-api/.env.local`. The preview reloads this file before each API request, so saving is enough; no restart is needed. It sets exact localhost allowed origins itself. `.env.local` is ignored by Git and the preview denies all server/secret files over HTTP. Do not use a generic static server when storing local credentials in this folder. Never put the key in frontend configuration. Old `OPENROUTER_API_KEY` and `CHAT_MODEL` entries are ignored and can be removed from the local secret file.

The agent reads three Markdown files on every request, in this order:

- `identity.md`: background, experience, projects, contact details and documented facts.
- `personality.md`: tendencies, preferences, values and interpersonal context.
- `voice.md`: tone, answer depth and communication style.

Saving updates the local preview without a restart. All three files must be nonempty, and their combined content is limited to 32 KiB. Deployed changes require redeploying the API. The retired `context.md` was removed; other Markdown files are never automatically ingested.

Keep the files concise and include only information suitable for public answers: their contents are sent to OpenAI with each question. Do not put keys or confidential information here. Stable role and prompt-protection boundaries stay in `lib/knowledge.mjs`; the three files supply facts, personality context and compatible style guidance. The system instructions refuse prompt and internal-instruction extraction, including transformed or encoded requests. This is a model instruction, not a guarantee of secrecy. The preview does not serve these files directly.

The separate Vercel project is `kai-morales-projects/kai-portfolio-chat` with Node 24. `OPENAI_API_KEY` is a sensitive environment variable and `CHAT_ALLOWED_ORIGINS` contains only the portfolio domains. Deploy from this directory with `vercel --scope kai-morales-projects deploy --prod`. The public endpoint is `https://kai-portfolio-chat.vercel.app/api/chat`. Vercel uses the documented default object `fetch(Request)` Web handler: https://vercel.com/docs/functions . `vercel.json` serves only the `public` directory as static output; the three profile Markdown files are included only in the function bundle. The deployed API has answered a live test question. The public website requires its chat frontend to be published and Vercel Authentication to be disabled for this dedicated project.

To keep the chat within a $10/year cash budget, turn off API credit auto-reload and set a project hard spend limit in OpenAI's dashboard. OpenAI documents both [prepaid billing](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing) and [hard spend limits](https://developers.openai.com/api/docs/guides/spend-limits). A spend limit may slightly overshoot while it propagates, so leave a buffer. The code's request bounds and throttle reduce accidental usage but do not replace a provider-level cap. Missing key returns 503 instead of a sample answer.

Throttling is best-effort and in-process: six requests per IP per minute, four concurrent provider requests, at most 2,000 tracked IPs. Serverless instances do not share this state; it is not a distributed abuse-prevention or spend guarantee. CORS does not authenticate callers. The Vercel adapter reads the platform-provided `x-real-ip`; do not deploy it behind an untrusted proxy without configuring trusted client-IP handling. Incoming body reads time out after five seconds (408) and cancel the stream; disconnect signals cancel them too. Provider timeout is 23 seconds, including response reading, keeping their combined budget within the function's 30-second duration.

Tests: `node --test tests/portfolio-chat.test.mjs tests/portfolio-context.test.mjs` from repository root. Tests inject provider responses, never use a live key, and do not establish the factual reliability of generated answers.
